Checkpoint 1: STEP 5:
WOW! This step was a doozy. It was challenging to apply flex to all aspects of the head, nav, and content. However, as I went along, all the tools and skills I’ve learned so far began to fall into place. I started feeling pretty overwhelmed with the state of my webpage. So, I decided to start by designing the layout I wanted across my webpage in Illustrator. I tried to keep it simple and design a template that I could replicate using the hierarchy and flex system. I will attach the images of these templates below my checkpoint. I began to style each of my pages from the same CSS sheet. This was the game changer: plugging in the section and div class codes to the CSS and watching visually how each element is in its own box and can be manipulated through this system was incredibly satisfying. The first two days I spent working on this were long and frustrating days, as I wasn’t sure when to apply wrap/nowrap, and the additional flex elements. However, once I got it, unifying the styling across the site became easier and easier.
